# STACKED! – Privacy Policy

This repository contains the official **Privacy Policy** for the mobile game **STACKED!**, developed by **XTLabs LLC**.

The policy is hosted publicly via **GitHub Pages** and is used to meet Google Play Store requirements.

---

## 🔐 About STACKED!

**STACKED!** is a free-to-play, lane-based merge and stacking mobile game available on Android.

The app itself does **not directly collect or store personal user data**.  
However, it uses trusted third-party services (such as advertising and analytics SDKs) that may collect limited device and usage information in accordance with their own privacy policies.

## 🛠️ Repository Purpose

This repository exists solely to:

- Host a public Privacy Policy
- Provide a stable, long-term URL for app store compliance
- Allow future updates without breaking store listings

No application source code is stored here.

To update the privacy policy:
